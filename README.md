# AWS Cloud Security & Infrastructure Portfolio

A comprehensive collection of hands-on AWS architecture and security deployments, demonstrating practical expertise in designing secure, scalable, and highly available cloud environments.

**Core Competencies**
* **Cloud Security:** Identity & Access Management (IAM), Network ACLs, Security Groups, Bastion Hosts.
* **Networking:** VPC Design, Public/Private Subnets, VPC Peering, NAT Gateways, Route Tables.
* **Infrastructure:** EC2, Application Load Balancers (ALB), Target Groups.
* **Storage & Databases:** S3 Static Hosting, Multi-AZ RDS deployments.

**Project Modules**

**1. Advanced Network Security & VPC Architecture**
* Designed custom VPCs with public/private subnet isolation.
* Implemented Bastion Hosts for secure remote access to private resources.
* Configured Network ACLs (NACLs) for granular traffic filtering and threat mitigation.
* Deployed NAT Gateways to allow outbound internet access for private subnets.

**2. Secure RDS Architecture**
* Architected a Multi-AZ database topology for High Availability.
* Isolated master and secondary database instances within private subnets.
* Hardened security groups to restrict database access strictly to authorized web servers.

**3. Application Load Balancing (ALB)**
* Provisioned Internet-facing Application Load Balancers.
* Configured Target Groups with health checks across multiple Availability Zones to ensure service resilience.

**4. VPC Peering Architecture**
* Established secure, private routing between isolated VPCs without traversing the public internet.

**5. IAM Security & Access Management**
* Engineered robust IAM policies following the principle of least privilege.
* Managed user identities, groups, and role-based access control (RBAC).

**6. S3 Static Website Hosting**
* Deployed and configured Amazon S3 buckets for highly available static website hosting.
